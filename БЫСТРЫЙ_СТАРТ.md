## ⚡ Рекомендации по производительности

### Количество потоков:
- **Оптимально:** Используйте все ядра CPU: `-t $(nproc)`
- **Минимум:** 1 поток тоже работает, но медленнее
- **Максимум:** Ограничений нет, Load Balancer распределит нагрузку

### Ребалансировка:
- **По умолчанию:** Каждые 5 секунд (оптимально для большинства случаев)
- **Быстрые сегменты (<1 мин):** Оставьте 5 секунд
- **Длинные сегменты (>10 мин):** Можно увеличить до 30-60 секунд

### Формат сегментов:
```
# Абсолютные значения ключей
abs START_KEY END_KEY up SEGMENT_NAME PRIORITY

# Пример:
abs 2217568061666849456128 2217863209572028803754 up winAv_01_ref1 5
```

---

## 🔧 Настройка интервала ребалансировки

Если нужно изменить интервал ребалансировки (по умолчанию 5 секунд):

1. Откройте `Vanity.cpp`
2. Найдите строку ~2655:
   ```cpp
   segmentSearch->EnableLoadBalancing(totalThreads, 5);
   ```
3. Измените `5` на нужное значение (в секундах)
4. Перекомпилируйте: `make -j8`
